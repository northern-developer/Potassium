# ptasm 0.3

**Status:** Assigned -- planned after 0.2.

The emulators: a QEMU CPU model and a Renode CPU model from the same
machine file, first QEMU by hand, then both generated, with programs
debuggable through their GDB servers. Moved from 0.2 when 0.2 was split
(2026-11-17): 0.2 is the machine file and the assembler, 0.3 the
emulators, 0.4 LLVM. Renode shares most of QEMU's generator (its CPUs
are tlib, derived from QEMU's TCG), so the two are one release.

Builds on 0.2's machine file: the semantics (0.2:E5.T1) and the system
and board layers (0.2:E5.T2), which this release implements.

**The writer is `ptsim`**: C++, a tool of its
own beside `ptasm`, sharing `libptasm` (statically linked) to read the
machine file. It writes the QEMU and Renode CPU models as source files; a separate project
builds them.
