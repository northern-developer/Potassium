# ptasm 0.4

**Status:** Assigned -- planned after 0.3.

The compiler: an LLVM backend from the same machine file, first by
hand, then generated, with LLDB as the debugger for custom CPUs. Moved
from 0.2 when 0.2 was split (2026-11-17).

Builds on 0.2's machine file (its semantics and ABI, 0.2:E5.T1; its
features and models, 0.2:E5.T2) and on 0.3's emulators, which run and
debug what it compiles.

**The writer is `ptllvm`**: C++, a tool of its
own beside `ptasm`, sharing `libptasm` (statically linked) to read the
machine file. It writes the LLVM backend as source files; a separate project
builds them.

The Rust `no_std` project (`ROADMAP.md`'s Goals) also needs, from the
same machine file, a `rustc` target specification (its data layout,
features and ABI), and a Rust toolchain whose LLVM includes the
generated backend.
