# ptasm 0.5

**Status:** Assigned -- planned after 0.4.

Board support: `ptbsp`, a writer of its own beside `ptasm`, `ptsim` and
`ptllvm`, sharing `libptasm` (statically linked). From a processor and a
board (0.2:E5.T2's system and board files) it writes the software that
runs on them, as source files a project builds: what `ptsim` writes is
the simulated hardware, what `ptbsp` writes runs on it, or on real
hardware such as an FPGA board. It needs a compiler first (0.4).

**Two options, with and without a C library**,
to be discussed well before this release starts. **picolibc is the
current target** for the C library option, after
comparing it with Embedded Artistry's `libc` and newlib (`E01-bsp.md`).
