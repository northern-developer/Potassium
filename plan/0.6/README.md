# ptasm 0.6

**Status:** Assigned -- planned: the documentation, before 1.0.

The documentation and how-tos, as a release of their own, once the
machine file, the assembler and the writers have settled (0.2 to 0.5):
a full minor version, so the documents describe a stable design rather
than one still moving. Definitely before 1.0.

What it would cover: the reference (`docs/SPEC.md`, the schema) checked
against the code; a tutorial, from nothing to a working CPU; a how-to
for each tool (`ptasm`, `ptsim`, `ptllvm`, `ptbsp`) and for the
downstream builds; documents generated from the machine files where
they can be, so they can't drift. Its first Epic, E1, is 0.2:E10, moved here: the tutorial, generated
cheat sheets, the API documentation.
